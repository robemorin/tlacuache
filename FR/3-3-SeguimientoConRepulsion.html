Actividad: Seguimiento de Trayectoria con Punto de Repulsión

Objetivo: Implementar un script en Python que simule el seguimiento de trayectorias complejas por parte de una partícula, evitando a la vez una zona de repulsión definida por un punto fijo en el espacio que podría ser una singularidad o un agujero negro virtual. Se compararán controladores con y sin compensación de velocidad.

Descripción del Problema:

Una partícula debe seguir (rastrear) una trayectoria deseada compleja en 2D, pero simultáneamente debe evitar acercarse demasiado a un punto de repulsión x_rep ubicado en el espacio. El controlador debe equilibrar dos objetivos conflictivos:

  1. Objetivo Primario: Mantener distancia mínima del punto de repulsión
  2. Objetivo Secundario: Minimizar el error de seguimiento de la trayectoria deseada

Instrucciones:

  • Parametrizar una trayectoria deseada como función del tiempo: xd(t), yd(t) usando expansiones en series trigonométricas para mayor sofisticación matemática.
  • Definir un punto de repulsión fijo: x_rep = (xr, yr) (ej: centro de la escena o dentro de la trayectoria)
  • Implementar al menos dos controladores:
    • Controlador 1 (P+Repulsión): u = -Kp * (x - xd) + Fr (sin feedforward)
    • Controlador 2 (P+FF+Repulsión): u = ẋd - Kp * (x - xd) + Fr (con feedforward)
    Donde Fr es la fuerza de repulsión (ver sección de control).
  • Usar el mismo integrador numérico (Euler o RK4) para ambos con verificación de estabilidad mediante análisis de autovalores.
  • Graficar trayectorias con el punto de repulsión claramente marcado (ej: círculo rojo).
  • OBLIGATORIO: Mostrar en las leyendas: Kp=[valor], Kr=[valor]
  • Calcular distancia mínima alcanzada al punto de repulsión en ambos casos.
⚠️ Punto de Repulsión:
El punto de repulsión es una región del espacio que la partícula debe evitar. Puede estar:
- En el centro de la trayectoria (máxima dificultad)
- En un extremo de la trayectoria (dificultad media)
- Fuera de la trayectoria (bajo riesgo pero con efecto)
Físicamente podría representar un obstáculo, un agente adversario, o una singularidad del sistema.
Estrategias de Control a Comparar:
Aspecto P + Repulsión P+FF + Repulsión
Ley de Control u = -Kp·e + Fr u = ẋd - Kp·e + Fr

Modelos de Fuerza de Repulsión

Opción 1: Repulsión Proporcional a Distancia Inversa Cuadrada

Simula una fuerza física tipo Coulomb:

d = ||x - x_rep|| (distancia a punto de repulsión)
Fr = Kr * (x - x_rep) / d² (si d > d_min)
Fr = Kr * (x - x_rep) / d_min² (si d ≤ d_min, saturado)

Donde d_min = 0.5 (distancia de saturación para evitar singularidad).

Opción 2: Repulsión Exponencial

Repulsión que crece rápidamente al acercarse:

Fr = Kr * (x - x_rep) * exp(-β * d)

Donde β = 2.0 (factor de decaimiento).

Opción 3: Repulsión por Potencial (Harmónico)

Similar a un potencial repulsivo armónico:

Fr = Kr * (x - x_rep) * max(0, d_safe - d) / d_safe

Donde d_safe = 1.5 es la distancia de seguridad deseada. Solo repele si d < d_safe.

Trayectorias a Seguir (Elige al Menos Una)

Opción 1: Lemniscata de Bernoulli

Parametrización:

x(t) = (a * cos(t)) / (1 + sin²(t))
y(t) = (a * cos(t) * sin(t)) / (1 + sin²(t))

Punto de repulsión sugerido: x_rep = [0, 0] (en el centro de la lemniscata)

Opción 2: Órbita Circular con Perturbación

Parametrización:

x(t) = R * cos(t) + A * cos(3*t)
y(t) = R * sin(t) + A * sin(3*t)

Parámetros: R = 2.5, A = 0.5. Punto de repulsión: x_rep = [0, 0]

Opción 3: Figura de Lissajous

Parametrización:

x(t) = 3 * sin(3*t + π/2)
y(t) = 3 * sin(2*t)

Punto de repulsión sugerido: x_rep = [1.5, 0] (en una región de alta densidad de trayectoria)

Opción 4: Espiral Cerrada

Parametrización:

r(t) = 2 + 0.3 * sin(5*t)
x(t) = r(t) * cos(t)
y(t) = r(t) * sin(t)

Punto de repulsión: x_rep = [0, 0] (en el centro)

Requisito de Control:
El sistema dinámico es: ẋ = u
Error de seguimiento: e = x - xd
Métricas:
  • RMSE de seguimiento: RMSE_traj = √(1/N * Σ||e||²)
  • Distancia mínima a repulsión: d_min = min(||x(t) - x_rep||)
  • Número de violaciones: Cuántas veces d < d_safe
  • Error máximo de seguimiento: e_max = max(||e||)

Métodos Numéricos (Implementar desde Cero)

Método de Euler Explícito

x[n+1] = x[n] + dt * f(x[n], u[n])

Runge-Kutta Orden 4 (RK4)

k1 = f(x[n], u[n])
k2 = f(x[n] + dt/2 * k1, u[n])
k3 = f(x[n] + dt/2 * k2, u[n])
k4 = f(x[n] + dt * k3, u[n])
x[n+1] = x[n] + dt/6 * (k1 + 2*k2 + 2*k3 + k4)

Parámetros Técnicos

  • Ganancia Proporcional (Seguimiento): Kp = 1.5
  • Ganancia de Repulsión: Kr = 2.0
  • Paso de Tiempo: dt = 0.001 s
  • Tiempo Total: T = 2π s (al menos una oscilación completa)
  • Número de Puntos: N = T / dt
  • Distancia Mínima Permitida: d_min = 0.5 m (aproximarse más = riesgo)
  • Distancia de Seguridad: d_safe = 1.0 m (distancia recomendada)
