Ejemplo de Rotación en 2D usando Python:

El siguiente código muestra cómo definir la matriz de rotación en 2D para un ángulo de $45^\circ$, aplicarla a un triángulo y graficar el resultado usando matplotlib:

import numpy as np import matplotlib.pyplot as plt # Definir el ángulo en radianes theta = np.radians(45) # Matriz de rotación en 2D R = np.array([ [np.cos(theta), -np.sin(theta)], [np.sin(theta), np.cos(theta)] ]) # Vértices del triángulo: [x, y] por columna # Añadimos el primer punto al final para cerrar la figura al dibujar vertices_originales = np.array([ [1, 4, 2, 1], # coordenadas X [1, 1, 4, 1] # coordenadas Y ]) # Aplicar la rotación a todos los vértices vertices_rotados = R.dot(vertices_originales) # Graficar plt.figure(figsize=(6, 6)) plt.plot(vertices_originales[0], vertices_originales[1], 'bo-', label='Original') plt.plot(vertices_rotados[0], vertices_rotados[1], 'ro-', label='Rotado (45°)') plt.fill(vertices_originales[0], vertices_originales[1], alpha=0.1, color='blue') plt.fill(vertices_rotados[0], vertices_rotados[1], alpha=0.1, color='red') plt.xlim(-5, 6) plt.ylim(-5, 6) plt.axhline(0, color='black', linewidth=0.8) plt.axvline(0, color='black', linewidth=0.8) plt.grid(True, which='both', linestyle=':', alpha=0.5) plt.legend() plt.title("Rotación de un polígono en 2D") plt.show()
