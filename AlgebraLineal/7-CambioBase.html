Ejemplo de Guía en Python usando SymPy (Caso para Subespacio de $\mathbb{R}^4$):

El siguiente script muestra cómo representar los vectores, calcular el punto en la base canónica, ortogonalizar los vectores de la base y encontrar las nuevas coordenadas del punto mediante la proyección ortogonal, comprobando la exactitud de los resultados al final.

import sympy as sp # 1. Definir los vectores de la base original B en R^4 v1 = sp.Matrix([1, -1, 0, 2]) v2 = sp.Matrix([0, 2, 1, -1]) v3 = sp.Matrix([1, 1, 1, 0]) # Lista de vectores originales base_original = [v1, v2, v3] # Coordenadas del punto P en la base B: [P]_B = [2, -1, 3]^T c_B = sp.Matrix([2, -1, 3]) print("--- Coordenadas en la Base Original (B) ---") print(f"[P]_B =\n{c_B}\n") # 2. Calcular las coordenadas en la base canónica C (obtenemos [P]_C) # Hacemos la combinación lineal: P = c1*v1 + c2*v2 + c3*v3 P = sum(c_B[i] * base_original[i] for i in range(len(base_original))) print("--- Coordenadas en la Base Canónica (C) ---") print(f"[P]_C =\n{P}\n") # 3. Aplicar Gram-Schmidt para obtener la base ortogonal B' = {u_1, u_2, u_3} base_ortogonal = sp.GramSchmidt(base_original) print("--- Vectores de la Base Ortogonal B' (Gram-Schmidt) ---") for i, u in enumerate(base_ortogonal): print(f"u_{i+1} =\n{u}\n") # 4. Calcular coordenadas de P en la base ortogonal B' mediante proyecciones # Dado que B' es ortogonal, cada coordenada c_i' se obtiene con: (P . u_i) / (u_i . u_i) c_B_prime = sp.Matrix([ P.dot(u) / u.dot(u) for u in base_ortogonal ]) print("--- Coordenadas en la Base Ortogonal (B') ---") print(f"[P]_B' =\n{c_B_prime}\n") # 5. Comprobación final # Reconstruimos P sumando c_i'*u_i y validamos que sea igual a [P]_C P_comprobado = sum(c_B_prime[i] * base_ortogonal[i] for i in range(len(base_ortogonal))) print("--- Comprobación ---") print(f"¿La reconstrucción coincide con [P]_C?: {P == P_comprobado}")
