Operaciones Básicas con Matrices

Realiza los siguientes cálculos a mano y escribe un programa en Python utilizando la librería numpy para comprobar tus resultados. Debes calcular:

  • Suma de matrices
  • Resta de matrices
  • Multiplicación de una matriz por un escalar
  • Multiplicación entre matrices (producto matricial)
A continuación se muestra un ejemplo. ¡Escribe el código tú mismo, no está permitido copiar y pegar el ejemplo!

Ejemplo:

import numpy as np

# Definir las matrices y el escalar
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
C = np.array([[1, 0, -1], [2, 1, 3]])
k = 3

# Suma de matrices
suma = A + B

# Resta de matrices
resta = A - B

# Multiplicación por escalar
mult_escalar = k * A

# Multiplicación entre matrices (producto matricial)
# Nota: También puedes usar np.dot(A, C)
mult_matrices = A @ C

print("Suma:\n", suma)
print("Resta:\n", resta)
print(f"Multiplicación por escalar ({k}):\n", mult_escalar)
print("Multiplicación entre matrices:\n", mult_matrices)
