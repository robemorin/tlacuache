Ficha de Trabajo: Representación Gráfica y Conversión de Números Complejos

Tiempo estimado de realización: 1 hora

Los números complejos pueden representarse como puntos o vectores en un plano bidimensional llamado **Plano de Argand**, donde el eje horizontal representa la parte real y el eje vertical la parte imaginaria. En esta ficha de trabajo, dominarás la transición geométrica de números complejos entre su forma cartesiana o binómica ($a+bi$) y su **forma exponencial o de Euler** ($re^{i\theta}$), y aprenderás a visualizarlos programáticamente usando vectores en Python.

Ejemplo de Conversión y Gráfico en Python:

A continuación se muestra un script guía que define un número complejo, lo convierte entre formas polar/exponencial, y grafica el vector correspondiente en el plano de Argand:

import cmath import numpy as np import matplotlib.pyplot as plt # 1. Definir un complejo en forma cartesiana z = -2 + 2j # Conversión a forma polar/exponencial r, theta = cmath.polar(z) print("--- Conversión Cartesiana -> Exponencial ---") print(f"Rectangular: {z}") print(f"Exponencial: {r:.4f} * e^(i * {theta/cmath.pi:.4f}*pi)\n") # 2. Definir un complejo en forma exponencial (ej: w = 3 * e^(i * pi/6)) w_r = 3 w_theta = cmath.pi / 6 w = cmath.rect(w_r, w_theta) print("--- Conversión Exponencial -> Cartesiana ---") print(f"Exponencial: {w_r} * e^(i * pi/6)") print(f"Rectangular: {w.real:.4f} + {w.imag:.4f}i\n") # 3. Graficar en el plano de Argand plt.figure(figsize=(6, 6)) # Dibujar vectores usando quiver (flecha desde el origen) plt.quiver(0, 0, z.real, z.imag, angles='xy', scale_units='xy', scale=1, color='blue', label='z = -2 + 2i') plt.quiver(0, 0, w.real, w.imag, angles='xy', scale_units='xy', scale=1, color='red', label='w = 3*e^(i*pi/6)') # Ajustes de límites y ejes plt.xlim(-5, 5) plt.ylim(-5, 5) plt.axhline(0, color='black', linewidth=0.8) plt.axvline(0, color='black', linewidth=0.8) plt.grid(True, which='both', linestyle=':', alpha=0.5) plt.legend() plt.title("Representación en el Plano Complejo de Argand") plt.xlabel("Eje Real (Re)") plt.ylabel("Eje Imaginario (Im)") plt.show()
