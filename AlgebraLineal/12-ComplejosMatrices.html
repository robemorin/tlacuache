Ficha de Trabajo: Representación Matricial de Números Complejos

Tiempo estimado de realización: 1 hora (a mano y validando en Python)

Un número complejo $z = a + bi$ puede mapearse exactamente a una matriz de $2 \times 2$ de la forma $\begin{bmatrix} a & -b \\ b & a \end{bmatrix}$. En esta ficha, resolverás las operaciones aritméticas básicas de números complejos utilizando este formalismo matricial. Descubrirás propiedades notables, como que el conjugado complejo equivale a la transposición matricial ($Z^T$) y el módulo al cuadrado equivale al determinante ($\det(Z)$).

Ejemplo de Operaciones Matriciales en Python:

El siguiente script muestra cómo representar números complejos en forma de matrices de $2 \times 2$ usando SymPy, realizar las operaciones y verificar los resultados de comprobación:

import sympy as sp # Definir matrices que representan z1 = 3 + 4i y z2 = 1 - 2i # z = a + bi -> [[a, -b], [b, a]] Z1 = sp.Matrix([ [3, -4], [4, 3] ]) Z2 = sp.Matrix([ [1, 2], [-2, 1] ]) print("--- Operaciones con Representación Matricial ---") suma = Z1 + Z2 resta = Z1 - Z2 mult = Z1 * Z2 div = Z1 * Z2.inv() # División z1 / z2 se hace multiplicando por la inversa print("Z1 + Z2 =\n", suma) print("\nZ1 - Z2 =\n", resta) print("\nZ1 * Z2 =\n", mult) print("\nZ1 * Z2^-1 (División) =\n", div) print("\n--- Comprobaciones Matriciales ---") print("Comprobación Suma (S - Z2 == Z1):", (suma - Z2) == Z1) print("Comprobación Resta (D + Z2 == Z1):", (resta + Z2) == Z1) # Comprobación de división: Q * Z2 == Z1 comp_div = div * Z2 print("Comprobación División (Q * Z2 == Z1):", comp_div == Z1) print("\n--- Propiedades Especiales ---") print("Transpuesta de Z1 (Equivale al conjugado z1_barra):\n", Z1.T) print(f"Determinante de Z1 (Equivale a |z1|^2 = 3^2 + 4^2): {Z1.det()}")
