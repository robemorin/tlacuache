Base Ortogonal (Proceso de Gram-Schmidt)

A continuación se te proporcionan matrices de $3 \times 3$. Debes aplicar el proceso de Gram-Schmidt a mano sobre las columnas de cada matriz para encontrar un conjunto ortogonal. Presta atención: algunas matrices pueden ser de rango deficiente, lo que significa que en algún paso podrías obtener un vector nulo. Debes identificar cuándo sucede esto y parar el proceso para ese vector.

Sugerencia para Python: Al igual que con el espacio nulo, la librería sympy cuenta con un método excelente para aplicar Gram-Schmidt y obtener resultados exactos con fracciones, lo que facilita comparar con lo que hiciste a mano.

Ejemplo en Python usando SymPy:

import sympy as sp

# Definir la matriz con los vectores columna
A = sp.Matrix([[1, 1, 0], [1, 2, 0], [0, 1, 2]])

# Extraer las columnas de la matriz como una lista de vectores
columnas = [A.col(i) for i in range(A.shape[1])]

# Aplicar Gram-Schmidt para obtener una base ortogonal
base_ortogonal = sp.GramSchmidt(columnas)

print("Vectores de la Base Ortogonal:")
for i, vec in enumerate(base_ortogonal):
    print(f"u_{i+1} =\n{vec}\n")
