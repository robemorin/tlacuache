Cálculo de Determinantes usando Python y Numpy

Escribe un programa en Python utilizando la librería numpy para obtener el determinante de las siguientes matrices. A continuación se muestra un ejemplo de cómo calcular el determinante de una matriz de 2x2. ¡Escribe el código tú mismo, no está permitido copiar y pegar el ejemplo!

Ejemplo:

import numpy as np

# Definir la matriz
A = np.array([
[3, 8],
[4, 6]])

# Calcular el determinante
det_A = np.linalg.det(A)

# Imprimir el resultado
print(f"El determinante de la matriz A es: {det_A}")
