Operaciones con Vectores

Realiza los siguientes cálculos a mano y escribe un programa en Python utilizando la librería numpy para comprobar tus resultados. Debes obtener:

  • Producto Punto
  • Producto Cruz
  • Ángulo entre los vectores (en grados o radianes)
A continuación se muestra un ejemplo. ¡Escribe el código tú mismo, no está permitido copiar y pegar el ejemplo!

Ejemplo:

import numpy as np

# Definir los vectores
u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

# Producto punto
producto_punto = np.dot(u, v)

# Producto cruz
producto_cruz = np.cross(u, v)

# Ángulo entre vectores
cos_theta = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
# Asegurar que el valor esté entre -1 y 1 para evitar errores de redondeo
cos_theta = np.clip(cos_theta, -1.0, 1.0)
angulo_rad = np.arccos(cos_theta)
angulo_grados = np.degrees(angulo_rad)

print(f"Producto punto: {producto_punto}")
print(f"Producto cruz: {producto_cruz}")
print(f"Ángulo: {angulo_rad:.4f} radianes ({angulo_grados:.2f} grados)")
