Cálculo del Espacio Nulo (Kernel)

A continuación se presentan 2 matrices cuadradas que tienen rango deficiente (es decir, su determinante es cero). Debes calcular el espacio nulo de cada una realizando la reducción por renglones (Gauss-Jordan) a mano y luego escribir un programa en Python para comprobar tus resultados.

Sugerencia para Python: Para obtener resultados exactos con fracciones (iguales a los que obtendrías a mano), es muy recomendable usar la librería sympy en lugar de scipy o numpy, ya que estas últimas entregan resultados decimales normalizados que son difíciles de comparar con tus cálculos manuales.

Ejemplo en Python usando SymPy:

import sympy as sp
# La respuesta propocionada no es única, también podría ser cualquier múltiplo de los vectores resultantes.

# Definir la matriz
# Ejemplo de matriz de 3x3 de rango deficiente
A = sp.Matrix([
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
])

# Calcular el espacio nulo (kernel)
espacio_nulo = A.nullspace()

print("Los vectores base que conforman el espacio nulo son:")
for i, vec in enumerate(espacio_nulo):
    print(f"Vector {i+1}:\n{vec}\n")
