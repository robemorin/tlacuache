Cálculo de una Base Linealmente Independiente

A continuación se te proporcionan matrices cuyos vectores columna forman un conjunto linealmente dependiente. Debes extraer un subconjunto de esos vectores columna que forme una base linealmente independiente realizando la reducción por renglones (escalonamiento) a mano, e identificando cuáles columnas corresponden a las columnas pivote. Posteriormente, escribe un programa en Python para comprobar tus resultados.

Ejemplo en Python usando SymPy:

import sympy as sp
# La respuesta propocionada no es única, también podría ser cualquier múltiplo de los vectores resultantes.

# Definir la matriz
A = sp.Matrix([
    [1, 2, 3, 4],
    [2, 4, 6, 8],
    [0, 1, 0, 1]
])

# Extraer la base del espacio columna (los vectores linealmente independientes)
base_columna = A.columnspace()

print("La base linealmente independiente (formada por las columnas pivote originales) es:")
for i, vec in enumerate(base_columna):
    print(f"Vector {i+1}:\n{vec}\n")
