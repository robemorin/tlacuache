Actividades: Gauss-Jordan Parte I, II y III.

Objetivo: Comprender y programar operaciones matemáticas entre filas de una matriz utilizando ciclos for. Esto es el fundamento principal para poder programar el método de eliminación de Gauss-Jordan en futuras actividades.

Ejemplo Base: Operaciones con Matrices

A continuación se proporciona un código inicial. En este código se define una matriz grande de 5x6 y una función para imprimirla de manera ordenada con dos decimales. Además, se incluye un ejemplo de cómo modificar los valores de una fila completa basándose en los valores de otra fila, utilizando un ciclo for.

import numpy as np

# 1. Definición de una matriz
A = np.array([
    [ 2.5,  1.0, -3.2,  4.1,  5.0,  8.2],
    [-1.2,  3.5,  2.0, -1.5,  0.5, -3.1],
    [ 4.0, -2.1,  1.5,  3.2, -1.0,  6.0],
    [ 0.5,  2.2, -4.0,  1.1,  3.3, -2.0],
    [-3.0,  1.5,  2.5, -0.5,  4.2,  1.5]
])

# 2. Función para imprimir la matriz cómodamente con 2 decimales
def imprimir_matriz(m):
    for fila in m:
        print("[", end="")
        for val in fila:
            # {:7.2f} asegura que cada número ocupe 7 espacios y tenga 2 decimales
            print(f"{val:7.2f}", end="")
        print(" ]")
    print("-" * 50)

print("Matriz Original:")
imprimir_matriz(A)

# 3. Ejemplo de operación entre filas usando un 'for'
# Objetivo: A la Fila 1 (índice 1) le vamos a sumar 2 veces la Fila 0 (índice 0)
# Fórmula matemática: F1 = F1 + (2 * F0)

alpha = 2.0
columnas = len(A[0]) # Obtenemos el número total de columnas

# Usamos un ciclo 'for' para recorrer elemento por elemento de la fila
for j in range(0, columnas):
    A[1][j] = A[1][j] + alpha * A[0][j]

print("Matriz después de la operación con 'for' (F1 = F1 + 2*F0):")
imprimir_matriz(A)
