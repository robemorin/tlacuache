Actividad: Animación de la Serie de Taylor para Coseno

Objetivo: Desarrollar un script en Python que aproxime la función cos(x) utilizando la Serie de Taylor en un punto de referencia distinto de cero y crear una animación que muestre cómo la aproximación mejora al aumentar el número de términos.

Ejemplo Base: Serie de Taylor para Seno

A continuación se muestra un ejemplo de cómo calcular y graficar la aproximación de la Serie de Taylor para sen(x) con 2 iteraciones:

import numpy as np #Solo para comparar el resultado con la función sin de numpy
import matplotlib.pyplot as plt

n = 2 #iteraciones
x = np.linspace(-10,10,300)

num = x.copy()
den = 1
sign = 1
Seno = sign * num / den

for i in range(1, n):
    sign *= -1
    num *=  x * x
    den *= (2 * i + 1) * (2 * i )
    Seno += sign * num / den

fig, ax = plt.subplots()
ax.plot(x, Seno, label='Aproximación de Taylor')
ax.plot(x, np.sin(x), label='Función seno', linestyle='dashed')

ax.legend()
ax.set_xlim(-10, 10)
ax.set_ylim(-1.5, 1.5)
ax.grid(True)
plt.show()

Instrucciones para el Coseno

  • El programa debe aproximar la función cos(x).
  • Debes elegir un punto de referencia a que no sea cero (por ejemplo, π/2, π, -π/2, etc.).
  • En lugar de un cálculo estático, debes implementar un algoritmo que genere una animación (puedes usar matplotlib.animation en Python).
  • La animación debe mostrar la gráfica real de cos(x) y cómo la curva de la Serie de Taylor se va adaptando a ella conforme se van agregando más términos (iteraciones).
